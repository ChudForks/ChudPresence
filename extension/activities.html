Activity API v2

Use apiVersion: 2 for programmable Activities that run inside a sandbox. Declare the page fields you need in pageAccess, then combine their snapshots with JavaScript in ChudPresence.onUpdate(). V2 supports public DOM and JSON reads, open shadow roots, media state, selected query parameters, scoped storage, and declared network requests.

One-time Chrome setting

Allow Activity scripts

Chrome is blocking Activity scripts until you enable the required setting for this extension.

  1. Open Chrome’s Extensions page.
  2. Chrome 138 or newer: open this extension’s Details and turn on Allow User Scripts. Earlier versions: turn on Developer mode.
  3. Return here and reload the Activity Library.
