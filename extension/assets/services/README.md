# Service assets

`discord.png` is Discord's unmodified 256 × 256 Clyde/default-avatar PNG,
downloaded from [Discord's CDN](https://cdn.discordapp.com/embed/avatars/0.png)
on October 18, 2026.

The default-avatar endpoint is documented in
[Discord's developer reference](https://discord.com/developers/docs/reference#image-formatting-cdn-endpoints).
